## Recommended Approach: Cloudflare (free + easy)

> Best option if PlatePilote's DNS is already on Cloudflare.

### Steps:
1. **DNS setup**: Add A record pointing to your EC2 public IP
   ```
   api.platepilote.com → A → 12.34.56.78
   ```
2. **Proxy toggle**: Set proxy to **Proxied** (orange cloud)
3. **SSL/TLS mode**: Cloudflare Dashboard → SSL/TLS → **Full (strict)**
4. **Auto HTTPS redirect**: ON

### Result:
- Cloudflare terminates SSL at edge
- Backend sees HTTP on port 80 (Cloudflare → EC2 via Cloudflare Tunnel or public)
- **No certbot needed** — CF auto-manages certificates
- DDoS protection, WAF, caching — **all included free**

### ⚠️ Prerequisite:
- Your domain MUST be on Cloudflare DNS (not Cloudflare registrar required, just DNS)
- EC2 must accept traffic on port 80 and 443 (Cloudflare IPs only for Full Strict)

### Security group (EC2):
```
Inbound:
  HTTP  80   0.0.0.0/0    (or Cloudflare IPs only)
  HTTPS 443  0.0.0.0/0    (or Cloudflare IPs only)
  SSH   22   YOUR_IP/32  (your dev machine only)
```

## Alternative 2: AWS ACM + ALB (recommended for EC2 + scaling)

### Steps:
1. **Request certificate** in AWS Certificate Manager (eu-west-3)
   ```
   aws acm request-certificate \
     --domain-name api.platepilote.com \
     --validation-method DNS \
     --region eu-west-3
   ```
2. **Validate domain**: Add the CNAME record to your DNS provider
3. **Create ALB**: AWS Console → EC2 → Load Balancers → Create ALB
4. **Attach ACM cert** to ALB listener (port 443)
5. **Redirect HTTP → HTTPS**: ALB listener rule on port 80 → redirect to 443
6. **Target group**: EC2 instance on port 8080

### Architecture:
```
User → HTTPS (443) → ALB → HTTP (8080) → EC2 Spring Boot
```

### Cost:
- ACM: **FREE**
- ALB: ~$18/month (not free tier eligible)
- Data transfer: ~$0.008/GB

## Alternative 3: Let's Encrypt (direct on EC2, $0)

### Prerequisites:
- Domain pointing to EC2 public IP
- Port 80/443 open in security group
- Nginx installed on EC2

### Install certbot:
```bash
sudo apt update
sudo apt install certbot python3-certbot-nginx -y
```

### Get certificate:
```bash
sudo certbot --nginx -d api.platepilote.com
```

### Auto-renewal (systemd timer):
```bash
# certbot sets up a systemd timer automatically
sudo systemctl status certbot.timer
sudo certbot renew --dry-run
```

### Nginx config:
```nginx
server {
    listen 80;
    server_name api.platepilote.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.platepilote.com;

    ssl_certificate     /etc/letsencrypt/live/api.platepilote.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/api.platepilote.com/privkey.pem;

    # Modern SSL config
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256;
    ssl_prefer_server_ciphers off;

    location / {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### Renewal:
```bash
# Test auto-renewal
sudo certbot renew --dry-run

# View timer status
sudo systemctl list-timers | grep certbot
```

## Spring Boot SSL config (when using Spring Boot directly)

If not using Nginx, add to application-prod.yml:
```yaml
server:
  port: 8080
  ssl:
    enabled: false  # SSL handled by Nginx / ALB / Cloudflare
  redirect-http-to-https: true  # Spring Boot redirect
```
