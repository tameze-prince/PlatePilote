# Beta Tester Guide — Notion Template (M4d)

## Structure Notion

Créer une page Notion partagée : `PlatePilote Beta v1 — Guide Testeurs`

### Sections

### 1. 🎯 Objectif du beta test
```
Tu fais partie des 50-100 premiers utilisateurs à tester PlatePilote.
Ton feedback nous permet de livrer une app qui marche pour de vrai.
Merci 🙏
```

### 2. 📲 Installation

**Android** :
1. Reçois l'invitation Firebase App Distribution par email
2. Ouvre le lien → Installe l'APK
3. Accepte les permissions

**iOS** (TestFlight) :
1. Reçois l'invitation TestFlight par email
2. Installe TestFlight depuis l'App Store
3. Accepte l'invitation → Télécharge PlatePilote

### 3. 🧪 User journey recommandée
```
1. Inscription → email ou Google/Apple Sign-In
2. Onboarding 7 étapes → réponds honnêtement
3. Génère ton 1er plan repas
4. Consulte la liste de courses
5. Ajoute un article au garde-manger (scan ou manuel)
6. Modifie ton budget dans Réglages
7. Essaie de swapper un repas
```

### 4. 📝 Feedback format

**Bugs** : screenshot + description + étapes pour reproduire
**UI/UX** : ce qui t'a gêné + suggestion
**Features** : ce qui manque

Envoyer à : zeufacktameze@gmail.com ou via formulaire Notion

### 5. ✅ Checklist testeur
- [ ] Inscription fonctionne
- [ ] Onboarding s'affiche correctement (check sombre + clair)
- [ ] Plan repas généré avec mes préférences
- [ ] Budget respecté (ou non — si non, c'est un bug important)
- [ ] Liste de courses s'affiche
- [ ] Garde-manger : ajout manuel OK
- [ ] Scan d'ingrédient fonctionne (si feature activée)
- [ ] Pas de crash pendant 5 min d'usage continu
- [ ] Déconnexion/reconnexion OK
- [ ] L10n française : pas de texte anglais dans l'app

### 6. 🎁 Récompense
3 mois Premium gratuit après le lancement public. Validé par Prince.
